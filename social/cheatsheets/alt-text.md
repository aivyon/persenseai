## PersenseAI Multimodal Reasoning Pipeline

Portrait infographic with seven connected stages: video, images, text, audio, and sensors become observations with time, confidence, and provenance; temporal evaluation uses Visual Reward; evidence reasoning maps support and contradiction; utility models information gain, uncertainty, redundancy, and counterfactuals; a bounded agent selects tools, updates state, replans, tracks budget, and stops; output is either a grounded answer or inconclusive stop.

## Agent Progress Reward

Portrait infographic showing the formula agent action to tool result to state change to progress reward to next action or stop. A green section lists nine positive components; a red section lists nine penalties. Bounded decisions are continue, request evidence, test contradiction, answer, and stop inconclusive. The closing statement says reward measures grounded resolution rather than confirmation of the original hypothesis.
