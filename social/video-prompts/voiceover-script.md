# Voiceover script

PersenseAI begins with video, images, text, audio, and sensor signals. They become structured observations with time, confidence, and provenance. Visual Reward tracks what changed over time. An evidence graph connects support, contradiction, and unresolved uncertainty to their sources. Evidence Utility estimates which observation mattered, while redundancy and cost remain visible. A bounded orchestration agent ranks registered tools, updates structured state, and tracks budget. Agent Progress Reward explains whether each action improved grounded resolution. When contradiction remains, it can replan—then return a cited answer or stop inconclusive.

**Word count:** 86

Delivery: calm, precise, lightly paced at approximately 130 words per minute. Avoid promotional emphasis; pause briefly after each research question.
