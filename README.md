# PersenseAI

Purpose-built static website for **PersenseAI** at `persenseai.com`.

PersenseAI is positioned as an AI agent for debugging Computer Vision, tracking, ReID, detection, occlusion, and video pipeline failures.

## Website

- Static HTML and CSS only
- No framework
- No build step
- GitHub Pages compatible
- Custom domain configured with `CNAME`

## Visual product concept

The homepage shows a visual product flow:

`Video + Logs + Tracks → Feature Table → Anomaly Detection → Agent Diagnosis → Report`

It includes pure HTML/CSS mockups for:

- failure cards
- track feature table
- SHAP-style feature contribution explanation
- final diagnostic report
