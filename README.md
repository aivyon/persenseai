# PersenseAI

Purpose-built static website for **PersenseAI** at `persenseai.com`.

PersenseAI is a visual debugging agent concept for Computer Vision, tracking, ReID, detection, occlusion, and video pipeline reliability.

## Website

- Static HTML and CSS only
- SVG assets committed in-repo
- No framework
- No build step
- GitHub Pages compatible
- Custom domain configured with `CNAME`

## Product flow

`Video + Logs + Tracks → Feature Table → Anomaly Detection → Agent Diagnosis → Report`

## Included visuals

- hero product visual with synthetic bounding boxes and track diagnostics
- workflow diagram (pipeline)
- failure cards
- feature table mockup
- SHAP-style feature contribution blocks
- debug report mockup
- optional demo/video placeholder
